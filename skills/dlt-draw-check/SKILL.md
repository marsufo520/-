# 大乐透开奖对奖

对「超级大乐透」追号做抓取、对奖与汇报。区分 **期**（一期开奖）和 **注**（一期里的一组号码）；一期可含多注。默认按常见 **10 期** 追号计划处理，除非用户另说。

## 硬性规则

- 结果只发到 **App 聊天**，不要发微信（微信留给工作）。
- 号码、奖金、奖池、进度只用来自真实抓取或本地缓存的数据，禁止编造。
- 前区 5 个不重复 01–35；后区 2 个不重复 01–12。
- 奖级按官方现行规则（第 26014 期起 7 个奖级）；追加只影响一、二等奖（+80%）。一、二等奖金额若待公布，照实写「待公布」。
- 开奖日通常为周一、周三、周六晚；当晚若还没出号，等 20–30 分钟再试一次，仍没有就短说未出号。

## 本地工具（优先）

若本机已有纯 Python 对奖助手（常见目录含 `dlt10.py`、`plans.json`），在该目录执行，不依赖用户个人电脑：

1. `python3 dlt10.py run` — 抓开奖 → 对所有计划 → 写 `results.json` / `report.html` / `summary.txt`
2. `python3 dlt10.py list` — 看计划进度
3. `python3 dlt10.py report` — 只用本地缓存重出报告（不联网）
4. `python3 dlt10.py draws -n 10` — 看最近开奖缓存
5. 新增计划：`python3 dlt10.py add --name "…" --start <期号> [--addon] --zhu "01 05 10 22 33 + 03 09"`（可多次 `--zhu`；默认 10 期、不追加）
6. 导入：`python3 dlt10.py import plans.json` 或 CSV（列：name,start_issue,periods,addon,front,back）
7. 删除：`python3 dlt10.py remove <id或名称>`

开奖来源顺序（工具内已实现）：体彩官方 API → 500 彩票网历史/单期详情 → 甘肃体彩网兜底。境外 IP 可能被官方 Edge 拦截，以工具实际成功源为准。

没有该工具时：用可靠公开开奖页抓本期前区/后区/奖池，再按同一奖级表对用户给出的每注逐一比对，并标明数据来源。

## 汇报格式（中文、简洁）

1. 若本期有中奖：开头醒目写「本期中奖」+ 哪一计划/哪一注 + 奖级 + 金额。
2. 最新一期：期号、开奖日期（含星期）、前区 5 号、后区 2 号、奖池。
3. 每个计划：本期每注命中（如 `2+1`）与奖级、进度（如 `6/10` 期）、累计投入、中奖、净额。
4. 附上本地报告路径（若有 `report.html`）。
5. 某计划已追满约定期数：提醒用户发新号码续上。
6. 无新开奖或抓取失败：一句话说清即可。

## 录入与变更

- 用户给新计划时确认：名称、起始期号、期数（默认 10）、是否追加、每注前区+后区。
- 改计划或删计划前说清影响，再改本地 `plans.json` 或走 `add`/`remove`/`import`。
- 定时开奖检查用 **例行任务**（skill 本身不排程）；例行任务应调用本 skill 的对奖与汇报步骤，并遵守「只发 App」。
